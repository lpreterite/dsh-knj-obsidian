## 为什么会有这条链

起因：2026-10-23 dsh-web 段错误崩溃循环（6 次 SIGSEGV）——本地嵌入路径把 llama.cpp 原生 addon 以进程内 import 加载进宿主主进程，Kaby Lake CPU 上 embed 挂死/段错误，一崩整个宿主陪葬。诊断与隔离复现记录见仓库 docs/2026-10-23-dsh-web-segfault-embed-handoff.md。

## v15：嵌入后端可选（KNJ_OBSIDIAN_EMBED=local|remote|off）

remote 模式：嵌入改调 OpenAI 兼容 POST {url}/embeddings（本部署 = axonhub http://100.93.42.43:8090/v1，模型 baai/bge-m3，1024 维），向量存本机 node:sqlite（~/.dsh/knj-obsidian/remote-embed/ 按库根隔离），刷新对账 = 页面 sha256 增量（未变页零 HTTP）。本机不加载任何模型/原生栈——引爆物消失。所有语义消费方（wiki_search_semantic / wiki_drill / wiki_query 兜底 / 触发层兜底 / 边栏自动+手动刷新）走同一分派点 selectSemanticRuntime。

## v16：设置面板化（18 个 KNJ_OBSIDIAN_* 环境变量迁入 DSH 设置页）

优先级铁律：env 覆盖 > 设置面板 > 内置默认（测试注入与临时覆盖不受影响）。semantic 组与 trigger 组均 volatile：设置页保存即热生效（local↔remote↔off 免重启）。

## 设置页可见性的三层（排障结论，缺一层就看不到）

1. 服务端行：profile 的 cordis.patch.yml 必须有 loader entry（CLI add/install 不合并 bundle patch，手工补 `- id: dsh-knj-obsidian` 两行）；设置行按 configEditor.configuration()（patch 文档）生成。
2. HTTP 通道：/api/obsidian-wiki/config 不能注册成独立 exact 路由（会被 routes.ts 的 prefix 路由遮蔽=静默 404）；由 prefix handler 在 store 解析前拦截委托 handleConfigRequest；settings 服务必须声明式 inject(['settings']) 捕获（防御式读取在 cordis 0.2.0 里不可见）。
3. 客户端注册：设置 UI 不为 describe 行自动生成导航——插件 client 必须 configForms.whileServed([ns], () => slots.inject('plugins.item', …)) 注册卡片（参照 dsh-client-ui-settings-web-search），且 dsh.client.inject 要加 client-ui-settings / client-ui-plugin-manager / client-locale。实现在 src/client/SettingsPage.tsx。

## LAN 编辑要点

非回环页面官方表单一律 memory 模式不可用（宿主设计）。LAN 改配置走 POST /api/obsidian-wiki/config：ops 形状 {"op":"set","path":["semantic","embedKey"],"value":…}——**path 是段数组、必须带 op:'set'**（漏 op 会被当空写，写个寂寞）；expectedRevision 冲突 409；embedKey 永不回传（留空=保持现值）。

## 本机部署参数

嵌入后端 remote @ http://100.93.42.43:8090/v1（axonhub），模型 baai/bge-m3（1024 维），密钥存于 profile patch 条目 config.semantic.embedKey（与 dsh-self-improved 同款明文模式）。换嵌入模型 = 维度变化 = 全量重建向量索引，此后不可随意更换。
